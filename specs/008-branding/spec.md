# Camply branding

## User stories

- Visitors recognize camply through the original tent-and-trees artwork throughout the app.
- Designers can use logos with the camply title alongside or below the artwork, or use the artwork with the title removed entirely.
- Visitors see the supplied Recreation.gov logo on its provider cards and the supplied portrait in Meet Justin.

## Acceptance criteria

- Horizontal, stacked, and icon-only SVG assets are available in light and dark variants. Lettering is outlined and the icon-only files contain no title paths.
- Navigation and footer use the horizontal logo; sign-in and invitation screens use the stacked logo; the home hero and favicons use the icon-only artwork.
- Logo proportions stay consistent across sizes and app theme changes. Assets load for root and prefixed deployments.
- The existing design system preview shows all three variations, and visual baselines reflect the intended branding changes.

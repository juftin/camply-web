## What the license is

AGPL-3.0 is a strong copyleft open-source license published by the Free Software Foundation. It grants anyone the freedom to view, run, modify, and share the software, provided derivative works keep the same license.

Unlike the standard GPLv3—which triggers source-sharing obligations only when compiled binaries or copies are distributed—the Affero clause extends that requirement to network interaction. If someone modifies the software and runs it as a hosted service for others to use over the web, those users also have the right to receive the complete source code.

## What it means for you

- **Using the hosted app or running camply privately:** You can use camply for free, run the CLI, or self-host an unmodified instance for yourself without needing to publish anything.
- **Modifying and distributing or hosting for others:** If you change camply and either distribute copies or operate your modified version over a network for other users, you must release your modified source code to them under the same AGPL-3.0 terms.
- **Contributing to the project:** Code submitted to this repository is licensed under `AGPL-3.0-or-later` so every improvement stays open to everyone.

As stated in the license text, camply is provided "as is" without warranty.

## Why camply chose AGPL-3.0

camply started with a simple goal: level the playing field so anyone can catch sold-out campsite cancellations without having to monitor booking sites around the clock or pay for a commercial alert service.

We chose AGPL-3.0 to guarantee that camply stays free and 100% open source forever. Requiring anyone who builds on or hosts a modified version of camply to share their source code prevents closed-source forks—including proprietary hosted services—and ensures that every improvement remains available to the whole camping community.

# Endpoint discovery and validation

All paths below are relative to `https://a1.reserveamerica.com/jaxrs-json`. This is an unofficial public frontend API, not an independently documented API contract. The upstream notebook and ReserveAmerica's shipped frontend JS supplied the request shapes. No credentials or raw live responses are committed.

No full campground dump/export was verified. Unscoped and contract-scoped search probes returned 401, so they are not treated as reliable replacements for the verified state search. The `www` and `api` hosts returned 403 in this environment. Authorization behavior varies by endpoint; failed requests must continue to raise, never look like empty availability.

Automated verification uses synthetic HTTP responses and SQLite: pagination, date windows and checkout clipping, exact statuses, day-use/phone-only filtering, DTO attributes, anonymous session refresh, HTTP/schema/pagination failures, dynamic brand state discovery, repeated atomic catalog refresh, provider isolation, stale records, rollback, migration seed lifecycle, and registry inclusion.

Verification results: `task check` passed repository-wide formatting, lint, all six import contracts, MyPy (139 files) and frontend TypeScript checks. The backend suite passed (901 tests, 24 environment/opt-in skips); release tests passed (17), frontend tests passed (340), and Pages tests passed (10) with production builds, Function bundling and real static/proxy HTTP verification. Installed wheel/sdist suites passed 66 cases on the first run; three base-install registry assertions still expected 12 providers and were updated to check all 13 plus the ReserveAmerica class, then rerun separately. No production behavior changed to address those assertions.

The migration head was exercised on fresh and previously versioned temporary SQLite databases; no operator database was modified. Docker's daemon is unavailable, so PostgreSQL migration smoke remains unverified. Full-country database ingestion has not been run; persistence and rollback have synthetic SQLite integration coverage.

Additional live pre-PR checks parsed complete availability responses for `NY_695` and `FLFS_1120158` on 2027-01-05 (both yielded zero eligible available sites for that night), and both generated campground URLs resolved to HTTP 200 overview pages. Positive availability was verified in the earlier Colorado scan.

## Nationwide catalog count

A subsequent read-only crawl on 2026-11-07 completed all 50 US states from the brand catalog without errors. After de-duplicating contract/facility identities, the directory contained **8,172 unique facilities**, of which **1,004** meet this provider’s native, verifiable, visible, overnight-camping criteria. The provider creates **0 separate recreation areas**: facility records map directly to campgrounds. Counts cover the US only, exclude Canadian provinces, and are not a count of individual campsites. No database ingestion was performed for this census.
